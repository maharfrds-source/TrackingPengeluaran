Konfigurasi Firebase Google

Hubungkan Firebase Project untuk login Google 1-klik

Cukup tempel objek firebaseConfig dari Firebase Console Anda:

Langkah 1x di console.firebase.google.com:
  1. Buat Project di Firebase Console.
  2. Di menu Authentication > Sign-in method, aktifkan Google.
  3. Di menu Firestore Database, klik Create database (Pilih Start in test mode).
  4. Di Project Settings, tambahkan Web App dan salin firebaseConfig ke kotak di atas.
